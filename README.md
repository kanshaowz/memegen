# 😂 MemeGen - Meme Generator

Create hilarious memes in seconds! A fast, fun, and free meme generator with multi-language support.

![MemeGen Screenshot](https://via.placeholder.com/800x400/FFD93D/1A1A2E?text=MemeGen+Screenshot)

## ✨ Features

- 🎨 **Upload Images** - Drag & drop or click to upload your own images
- 🔥 **Hot Templates** - Popular meme templates ready to use
- 📝 **Add Text** - Customize top and bottom text with various styles
- 🎨 **Style Controls** - Font size, colors, and outline customization
- 💾 **Download** - Save your memes as PNG
- 🌍 **Multi-language** - EN, 中文, ES, 日本語, 한국어

## 🚀 Live Demo

Visit: https://kanshaowz.github.io/memegen

## 🛠️ Technologies

- HTML5 Canvas
- Vanilla JavaScript
- CSS3 with Flexbox/Grid
- Google Fonts

## 📦 Installation

```bash
git clone https://github.com/kanshaowz/memegen.git
cd memegen
open index.html
```

## 📝 Usage

1. Upload an image or select a template
2. Add your text (top and/or bottom)
3. Customize font size and colors
4. Click Download to save your meme
